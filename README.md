# AI: Useful, Fallible, Worth Checking

A one-page explainer about artificial intelligence, written for classmates. It covers what AI is, what it does well, three case studies where it went wrong (deepfake fraud, outages, agents escaping a test), a timeline, and possible futures. Every claim is labelled as a fact, an interpretation or a prediction.
